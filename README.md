- Consistent color theme (HEX) and Roboto Google Font

- Box model spacing, borders and shadows
- Skills table with alternating row colors
- Contact form with labels, placeholders and validation

- Fixed "Back to Top" button and smooth scrolling
- Styled `<hr>` separators
